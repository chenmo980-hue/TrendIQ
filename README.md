# 读势 · TrendIQ - A股多周期技术分析与AI智能视觉形态研判系统

一个现代化的 A 股全栈技术分析与量化研判系统，面向 A 股交易场景深度定制：

- **指标分析模式**：输入 A 股代码、中文简称或拼音联想搜索 → 实时抓取行情与 K 线（日线 + 1/5/15/30/60/90/120 分钟多周期）→ 毫秒级计算 MA / MACD / RSI / BOLL / KDJ / 支撑压力位 → 规则引擎输出多空评分与攻防点位 → 一键调用 AI 综合深度研判（支持 Gemini 3.7 Flash 及本地量化引擎无缝降级）。
- **图表识别模式**：上传/粘贴任意行情软件（同花顺、通达信、雪球、TradingView 等）的 K 线截图 → 多模态视觉模型自动解构经典形态（W底、头肩底、上升通道、三角形收敛）、标记关键支撑阻力线并在图表上矢量叠加渲染。

## 快速开始（本地运行）

### 1. 安装依赖
```bash
npm install
```

### 2. 配置环境变量
复制根目录的 `.env.example` 为 `.env`：
```bash
cp .env.example .env
```
在 `.env` 中填入你的 Gemini API Key（可在 [Google AI Studio](https://aistudio.google.com/app/apikey) 免费获取）：
```env
GEMINI_API_KEY=你的Gemini_API_Key
PORT=3000
```
> 💡 **提示**：即使未配置 `GEMINI_API_KEY`，系统也内置了**高精度量化规则引擎**，点击 AI 解读按钮依然能秒级生成详尽的四维技术分析报告，永不中断！

### 3. 启动开发服务器
```bash
npm run dev
```
打开浏览器访问：[http://localhost:3000](http://localhost:3000)

### 4. 生产打包与启动
```bash
npm run build
npm start
```

## 常见问题与排查指南

### 1. 为什么点击「AI 综合解读」报 `403 Request not allowed`？
- **原因**：如果使用的是早期旧版本调用 Anthropic/境外接口，或者在大陆网络环境下直接调用未走代理的海外大模型接口，会被官方防火墙拦截并返回 403。
- **解决方案**：
  1. 当前最新版本已全面集成 **Gemini 3.7 Flash**，并带有**本地量化引擎自动降级机制**，无论有无 Key 或网络是否受限均可正常运行。
  2. 若需开启最高质量的云端大模型解读，请在 `.env` 中配置 `GEMINI_API_KEY`，并在本地终端配置科学上网代理环境（例如 `export https_proxy=http://127.0.0.1:7890`）。

### 2. 画面布局说明
- 桌面宽屏（PC 端）采用金融交易终端经典的 **左右 7:3 黄金比例布局**：左侧为宽幅交互式 K 线图表与指标波形，右侧为规则评分、支撑阻力与 AI 深度解读。
- 移动端/平板端会自动自适应为单列响应式流式布局。
